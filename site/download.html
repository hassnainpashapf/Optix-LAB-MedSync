Install in 3 steps

Windows

  1. Download the .exe installer matching your Windows version using a button above.
  2. Run it and follow the setup wizard (Next → Install).
  3. Launch Optix LAB MedSync from the desktop or Start menu and log in.

macOS

  1. Download the .dmg.tar.gz file using the button above, then extract it to get the .dmg.
  2. Open it and drag Optix LAB MedSync into Applications.
  3. Open from Applications (first launch: right-click → Open) and log in.
