Bundled Latin fonts for the Lab Profile PDF renderer.
Source: Google Fonts CSS API (fonts.googleapis.com / fonts.gstatic.com).
Families: Inter, Plus Jakarta Sans, Roboto, Poppins, Open Sans, Lato, Montserrat.
Each family's SIL Open Font License is included beside its CSS and WOFF2 files.
Font binaries are embedded in PDF rendering documents so desktop export works offline.
